# EventFlow Product Requirements Document (PRD)

## Version
1.0 MVP

## Product Name
EventFlow

## Vision

EventFlow is a modern event management platform that enables event organizers to create events, manage guests, generate secure QR invitations, and perform fast digital check-ins.

The platform is designed for weddings, graduations, churches, conferences, corporate events, birthdays, and other private or public events.

---

# Problem Statement

Many event organizers still manage invitations manually.

Common problems include:

- Printed invitations can be copied.
- Guests lose entrance cards.
- Organizers don't know attendance in real time.
- Families receive multiple paper entrance cards.
- Check-in is slow.
- No attendance reports exist after the event.

---

# Solution

EventFlow digitizes the entire invitation and check-in process.

Organizers can:

- Create events
- Add guests
- Generate QR invitations
- Track attendance
- View live statistics
